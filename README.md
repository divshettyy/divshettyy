### About

4-year VAPT engineer and bug bounty hunter. I build my own offensive tooling instead of relying on off-the-shelf scanners — and wire AI into every phase of the engagement loop.

- 🔍 **Bug bounty** — web app pentesting, exploit chaining, disclosure
- 🛠️ **Tool builder** — privacy-first, self-hosted alternatives to SaaS tools
- 🤖 **AI-augmented security** — Claude-driven recon → scan → triage → report automation
- 🏆 **Certs:** CEH · CRTP · CAISP · BFSI Specialist
- 📫 Reach me on [LinkedIn](https://www.linkedin.com/in/divith-shetty)
